# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text at that link applies to every space the project uses: issues, pull requests, discussions and any related channels.

## In short

- Be respectful and assume good intent.
- Give and accept constructive feedback about the work, never about the person.
- Harassment, discrimination, personal attacks and publishing others' private information are not acceptable.

## Reporting

Report unacceptable behaviour to the maintainer through a private GitHub Security Advisory on this repository, or by contacting the maintainer listed on the repository profile. Reports are handled confidentially. Maintainers may remove, edit or reject contributions and may temporarily or permanently ban contributors who violate this code of conduct, following the enforcement guidelines in the Contributor Covenant.
